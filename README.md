# Sweets X B

🍰 Sweet treats made from scratch. This app showcases a small, home-based bakery, delivering happiness one dessert at a time.

---

This repository is public to host the web application, but all development, testing, and maintenance are managed by the project owner.

> **Security Note:** Do **not** commit API keys, passwords, or other sensitive data. Use environment variables for sensitive configuration and add `.env` files to `.gitignore`.

Use the npm scripts below to manage local development, code quality, testing, formatting, dependency management, and production builds.

# Scripts

This project uses npm scripts to provide consistent commands for development, code quality, testing, formatting, dependency management, and production builds.

---

## Development

### `npm run dev`

Starts the Vite development server for local development.

### `npm run preview`

Starts a local server to preview the production build generated by Vite.

## Code Quality

### `npm run lint`

Runs Biome checks against the project.

Biome is responsible for code quality checks, formatting validation, and import organization.

This command does **not** modify files.

### `npm run lint:write`

Runs Biome checks and automatically applies safe fixes.

Use this command to automatically fix issues such as:

- Import organization
- Formatting
- Safe Biome lint fixes

### `npm run check`

Runs the project's primary validation checks:

1. Biome checks
2. Vitest tests
3. TypeScript compilation checks

This command does **not** modify source files.

## Formatting

### `npm run format`

Checks the project's formatting using Biome.

This command does **not** modify files.

### `npm run format:write`

Automatically formats supported project files using Biome.

Supported files include:

- TypeScript
- TSX
- JavaScript
- JSON
- CSS
- Markdown
- Other Biome-supported file types

## Testing

### `npm run test`

Runs the test suite once using Vitest.

### `npm run test:watch`

Runs Vitest in watch mode and automatically re-runs tests when files change.

### `npm run coverage`

Runs the Vitest test suite and generates a code coverage report.

> **Testing Framework:** This project uses **Vitest** for unit and component testing.

## Build

### `npm run build`

Validates and builds the application for production.

The process runs:

1. Biome checks

## Dependency Management

### `npm run audit`

Runs `npm audit` to check installed dependencies for known security vulnerabilities.

### `npm run fresh-install`

Removes `node_modules` and performs a clean installation using the existing `package-lock.json`.

> **Windows PowerShell:** This script uses PowerShell and is intended for Windows development environments.

This command does **not** intentionally update dependency versions.

### Updating dependencies

For routine dependency updates within the version ranges defined in `package.json`, use:

```bash
npm update
```
